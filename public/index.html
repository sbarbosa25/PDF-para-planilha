Leitor de PDF para Excel

Sobe o documento, a IA lê e organiza os dados. Funciona com PDF digital e escaneado.

2. Destino:
A IA encaixa os dados nas colunas do arquivo e devolve preenchido para baixar.
Os dados são anexados na próxima linha em branco deste arquivo, no servidor. Ninguém precisa baixar nada.
Registre uma planilha (.xlsx com cabeçalho) para ela aparecer na lista acima.
Você escolhe o arquivo uma vez e autoriza a gravação. Cada leitura grava nele sem baixar cópia.
Seu navegador não suporta gravação direta em arquivo local. Use o Chrome ou o Edge, com o site em HTTPS ou localhost. Enquanto isso, use uma das outras opções.
Clique em qualquer célula ou cabeçalho para editar. Nada é salvo até você confirmar.
